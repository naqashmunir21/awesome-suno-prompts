## 💡 Pro Tips for Afrobeats/Amapiano in Suno

### Amapiano Non-Negotiables
1. **"Log drum bassline" + "3-step pattern"** — The genre fingerprint
2. **"115 BPM exactly"** — Not 110, not 120. The bounce lives at 115.
3. **"Jazzy extended chords (maj9, 13)"** — Basic triads sound like preset packs
4. **"Kabza De Small / MFR Souls / Kelvin Momo style"** — Namedrop producers for style anchor

### Afrobeats Essentials
1. **"3-2 clave rhythm"** — Even if not explicit, the ghost note feel
2. **"Syncopated kick pattern"** — Kick on 1, &, 3, a (the Afrobeats pocket)
3. **Namedrop current artists** — Rema, Asake, Ayra Starr, Tems, Tyla, Seyi Vibez
4. **"Log drum + 808 hybrid"** — The 2024 mainstream sound

### Fusion Success Formulas
| Fusion | Ratio | Key Bridge Element |
|--------|-------|-------------------|
| Afrobeats + Jersey Club | 60/40 | Log drum under stutter kicks |
| Afrobeats + Phonk | 50/50 | Cowbell on off-beats + 3-step |
| Afrobeats + Drill | 50/50 | 3-2 clave ghost notes under drill hats |
| Afrobeats + Amapiano | 50/50 | Dual bass: log drum + 808 |
| Afrobeats + Latin | 60/40 | Dembow rhythm + 3-2 clave |

### Negative Constraints (Critical)
```
NEGATIVE: no generic "world music" percussion, no cheesy marimba presets,
no 4-on-the-floor on Amapiano, no major pentatonic only (use extended chords),
no quantized-perfect timing (humanize percussion), no thin-sounding bass
```
