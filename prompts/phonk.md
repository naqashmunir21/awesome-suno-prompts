## 💡 Pro Tips for Phonk in Suno

### The Non-Negotiables
1. **"Half-time at 140 BPM"** — Not 70, not 130. The drift feel lives at 140 half-time.
2. **"Cowbell on OFF-beats"** — Downbeat cowbell = classic Memphis. Off-beat = drift phonk.
3. **"Distorted 808 cowbell"** — Clean cowbell sounds like a preset. Distortion = phonk.
4. **"Memphis vocal chops pitched -6st"** — The sweet spot. -12 = too muddy, -3 = not phonk enough.
5. **"Aggressive sidechain (-12dB minimum)"** — The ducking IS the groove.

### Negative Constraints (Critical)
```
NEGATIVE: no clean cowbell, no 4-on-the-floor kick, no major key (unless melodic),
no quantized-perfect hi-hats (need triplet swing), no thin 808 (must be sub-heavy),
no reverb on cowbell (dry and distorted), no long intros (gym edits), 
no happy melodies (unless melodic subgenre), no acoustic instruments (unless hybrid)
```

### Functional Structures
**Gym Edit (30s):**
```
[INTRO 4] → [DROP 16] → [BREAK 4] → [DROP 16] → [OUTRO 4] = 44 bars @ 140 BPM = ~30s
```

**Car Edit (2-3min):**
```
[AMBIENCE 16] → [BUILD 16] → [DROP 32] → [BREAKDOWN 16] → [DROP 32] → [OUTRO 16]
```

**TikTok Loop (15s):**
```
[DROP 8] → [DROP 8 VARIATION] = 16 bars @ 140 BPM = ~15s (seamless loop)
```
