## Trending Prompt Templates (Copy-Paste Ready)

### The "Gym Edit" Formula (Works for Phonk, Corridos, Afro-Phonk)
```
[GENRE] gym edit, 30s loop structure (intro 4 → drop 16 → break 4 → drop 16 → outro 4),
[signature rhythm], [signature bass], [signature vocal treatment],
aggressive sidechain, zero dead space, loopable,
BPM: [140 for phonk/tumbados], Key: [Minor]
```

### The "Dance Challenge" Formula (Works for Jersey, K-Pop, Amapiano)
```
[GENRE] dance challenge, 30s exactly, 
4-bar instrumental hook → 8-bar vocal hook (point choreography) → 
8-bar variation → 4-bar breakdown → 4-bar build → matches bar 1,
[signature rhythm], major key for accessibility,
BPM: [135 Jersey / 115 Amapiano / 128 K-Pop], Key: [Major]
```

### The "Heartbreak Loop" Formula (Works for Sad Sierreño, Melodic Phonk, R&B)
```
[GENRE] heartbreak, [intimate instrumentation], 
vulnerable vocal style, no percussion or minimal,
slow tempo felt as half-time, 
lyrical theme: [specific heartbreak scenario],
BPM: [70-95], Key: [Minor]
```
