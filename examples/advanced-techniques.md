Master these patterns to go from "good" to "chart-quality" consistently. Each technique includes a copy-paste template and real examples.

## 1. Progressive Arrow Notation (Dynamic Evolution)

**Concept:** Tell Suno exactly how the song evolves over time using `→` arrows with timestamps.

### Template
```
[Intro texture] → [Verse instrumentation] → [Pre-chorus build] → 
[Chorus full arrangement] → [Bridge breakdown] → [Final chorus maximal] → 
[Outro strip-down]
BPM: [X], Key: [Y], Suno Version: [V4.5/V5]
```

### Real Example: Cinematic Trailer
```
Solo cello, intimate, dry → piano enters at 0:15, subtle → 
strings swell at 0:30, harmonic tension → 
full orchestra at 1:00, brass fanfare, percussion drive, choir pads → 
sudden drop to piano + cello at 2:15, sparse, emotional → 
crescendo to massive finale at 2:45, all forces, sustained chord
BPM: 72, Key: D Minor, Suno Version: V5
```

### Pro Tips
- Use timestamps (`at 0:45`, `at 1:30`) for precision
- Specify what **enters** or **leaves** at each transition
- Keep each segment focused (3-5 elements max)
- V5 handles this better than V4.5

## 2. Layered Production Specification (The "Stem" Method)

**Concept:** Define each production layer explicitly — foundation, rhythm, harmony, melody, vocals, FX.

### Template
```
[Foundation] [Bass/sub description: tone, pattern, processing]
[Rhythm] [Drum pattern + percussion: kick, snare, hats, extras]
[Harmony] [Pad/chord synth: voicing, movement, stereo width]
[Melody] [Lead instrument: scale, phrasing, articulation]
[Vocals] [Style per section: verse/chorus/bridge processing]
[FX] [Texture, transitions, ear candy: risers, chops, delays]
BPM: [X], Key: [Y], Suno Version: [V4.5/V5]
```

### Real Example: Modern R&B
```
[Foundation] Deep 808 bass, sub-heavy (40-60Hz), sidechained to kick, slight distortion
[Rhythm] Trap hi-hats (1/32 rolls on fills), claps on 2&4 with reverb tail, rimshot accents, shaker 1/16
[Harmony] Juno-106 pads, wide stereo, slow attack, filter sweep opening over 8 bars, 7th/9th voicings
[Melody] Rhodes electric piano, pentatonic runs, chorus effect, counter-melody in chorus
[Vocals] Breathily intimate verse (dry, compressed) → doubled + harmonized chorus (plate reverb 2.5s) → ad-lib runs, falsetto bridge
[FX] Vinyl crackle intro, vocal chops on downbeats, 1/4 note delay throws on last word, riser sweeps
BPM: 78, Key: Db Major, Suno Version: V5
```

## 3. Genre Fusion Formula (Ratio-Based Blending)

**Concept:** Combine 2-3 genres with explicit percentages. Suno understands ratios better than vague "blends."

### Template
```
[XX]% [Primary Genre] ([signature elements: instruments, rhythm, vocal style])
+ [YY]% [Secondary Genre] ([signature elements])
+ [ZZ]% [Accent Genre] ([signature elements])
[Vocal approach], [Structure note], [Key moment]
BPM: [X], Key: [Y], Suno Version: [V4.5/V5]
```

| Fusion | Ratio | Signature Elements | Viral Use Case |

| **Indie + Phonk** | 55/35/10 | Jangly guitars, lo-fi aesthetic + cowbell, distorted 808s, Memphis vocals + pop structure | Gym/editing music |
| **Afrobeats + Pop** | 60/30/10 | Log drums, 3-2 clave, Amapiano piano + radio hooks, synth leads + polished vox | Summer radio, dance challenge |
| **K-Pop + Hyperpop** | 50/40/10 | Idol vocals, rap line, performance structure + glitchy production, pitch-shifted vox + maximalist drop | Gen Z maximalism |

| **Phonk + House** | 50/40/10 | Memphis vocals, cowbell, distorted bass + 4x4 kick, jackin' hats + festival energy | Rave phonk, speed house |

## 4. Vocal Effects Mapping (Section-by-Section Processing)

**Concept:** Different vocal FX per section = professional dynamic range.

### Template
```
[Verse] [Effect chain]
[Pre-Chorus] [Effect chain]
[Chorus] [Effect chain]
[Bridge] [Effect chain]
[Final Chorus] [Effect chain]
BPM: [X], Key: [Y], Suno Version: [V4.5/V5]
```

### FX Vocabulary
| Effect | Suno Keywords |
|--------|---------------|
| Dry/Intimate | dry, close-mic, no reverb, compressed, whispered |
| Doubled | doubled, double-tracked, thickened |
| Harmonized | harmonies, layered harmonies, 3-part harmony |
| Reverb Types | plate reverb, hall reverb, room reverb, spring reverb |
| Delay | 1/4 note delay, 1/8 note delay, ping-pong delay, delay throws |
| Creative | telephone filter, bandpass filter, lo-fi filter, megaphone, vocoder, autotune, pitch-shift |
| Width | wide, stereo spread, panned harmonies |

### Real Example: Emotional Pop Ballad
```
[Verse] Dry, close-mic, intimate, subtle compression, whispered delivery, no reverb
[Pre-Chorus] Slow reverb bloom (plate, 1.8s), subtle doubling, high-pass automation opening up
[Chorus] Large hall reverb (3.5s), triple-tracked, low harmony + high falsetto, wide stereo
[Bridge] Telephone filter (bandpass 400-3000Hz), raw emotion, cracks allowed, mono center
[Final Chorus] Stadium reverb (5s), 5-layer stack, ad-lib runs, 1/4 note delay throws on last word, maximum width
BPM: 72, Key: Eb Major, Suno Version: V5
```

## 6. Negative Constraint Pattern

**Concept:** Tell Suno what NOT to do. Prevents common failure modes.

### Template
```
[Positive prompt]
NEGATIVE: no [unwanted element], no [unwanted element], avoid [style], exclude [instrument]
BPM: [X], Key: [Y], Suno Version: [V4.5/V5]
```

### Common Negative Constraints
```
NEGATIVE: no cheesey synth leads, no generic EDM buildups, avoid stock preset sounds
NEGATIVE: no muddy low end, no harsh sibilance, no over-compressed dynamics
NEGATIVE: no sudden genre switches, no jarring transitions, avoid cliché chord progressions
NEGATIVE: no AI artifacts, no vocal glitches, no timing drift, no repetitive loops
NEGATIVE: no copyrighted melodies, no direct artist impersonation, no explicit content
```

### Real Example: Clean Modern Pop
```
Infectious synth-pop, female powerhouse vocals with layered harmonies,
pulsing 808 bass, euphoric build-ups, modern radio production,
vocal harmonies on chorus, BPM: 128, Key: C Major
NEGATIVE: no 2010s dubstep wobbles, no generic "whoa-oh" chants, avoid nursery rhyme melodies, no excessive autotune artifacts, no thin-sounding drums
Suno Version: V5
```

## 7. Structural Tagging (Explicit Song Map)

**Concept:** Label each section for Suno to follow precisely.

### Template
```
[INTRO] [Description - bars, instrumentation, energy]
[VERSE 1] [Description]
[PRE-CHORUS] [Description]
[CHORUS] [Description]
[VERSE 2] [Description]
[PRE-CHORUS] [Description]
[CHORUS] [Description]
[BRIDGE] [Description]
[CHORUS] [Description - maximal]
[OUTRO] [Description]
BPM: [X], Key: [Y], Suno Version: [V4.5/V5]
```

### Real Example: Standard Pop Structure
```
[INTRO] 4 bars, filtered synth pad + kick only, energy 2/10
[VERSE 1] 16 bars, dry vocals, minimal drums (kick + shaker), bass enters bar 9, energy 4/10
[PRE-CHORUS] 8 bars, snare roll build, riser synth, vocals double, energy 7/10
[CHORUS] 16 bars, full drums, bass, synths, harmonies, hook melody, energy 10/10
[VERSE 2] 16 bars, added percussion, counter-melody, energy 5/10
[PRE-CHORUS] 8 bars, faster build, vocal ad-libs, energy 8/10
[CHORUS] 16 bars, maximal, added vocal stacks, energy 10/10
[BRIDGE] 8 bars, breakdown to piano + vocal only, emotional peak, energy 3/10 → 6/10
[CHORUS] 16 bars, maximum everything, ad-libs, key change +1 semitone optional, energy 11/10
[OUTRO] 8 bars, chorus hook repeats, fade with filter sweep, energy 10→1/10
BPM: 122, Key: A Major, Suno Version: V5
```

| Rush | rushing, urgent, pushed forward |
| Drag | dragging, laid-back, behind the beat |

## 9. Frequency & Spatial Instructions

**Concept:** Guide the mix — width, depth, frequency balance.

### Vocabulary
| Dimension | Keywords |
|-----------|----------|
| Width | wide stereo, mono center, hard-panned, narrow, mid-side |
| Depth | front/back, reverb distance, dry/wet balance, intimate vs distant |
| Frequency | sub-heavy, bass-forward, mid-focused, bright, airy, dark, warm |

### Real Example: Club Track Mix Notes
```
Festival main stage banger, massive synth drops, festival-ready energy,
pulsing sub-bass, euphoric builds, sidechain compression, crowd-hyping elements,
MIX: Sub-bass mono below 100Hz, wide stereo synths above 500Hz,
lead synth center with wide reverb tail, vocals upfront dry,
drums punchy mid-forward, sidechain ducking -6dB on bass from kick
BPM: 128, Key: C Minor, Suno Version: V5
```

## 10. Combination: The "Pro Template" (All Techniques Together)

```
[INTRO] 4 bars, filtered Juno pad + vinyl crackle, mono → stereo widening, energy 2/10
[VERSE 1] 16 bars, dry intimate vocals, kick + shaker only, sub-bass enters bar 9, energy 3/10
[PRE-CHORUS] 8 bars, snare roll 1/16→1/32, riser sweep, vocal doubles, filter opens, energy 7/10
[CHORUS] 16 bars, FULL: 909 kick, 808 bass (sidechained), claps 2&4, 1/16 hats, 
wide supersaw chords, lead pluck melody, triple-tracked vocals + harmonies, energy 10/10
[VERSE 2] 16 bars, add percussion loop, counter-melody, vocal ad-libs, energy 5/10
[PRE-CHORUS] 8 bars, faster build, pitch-up riser, energy 8/10
[CHORUS] 16 bars, MAXIMAL: add brass stab, vocal chops, delay throws, energy 11/10
[BRIDGE] 8 bars, breakdown: piano + vocal only, telephone filter on vox, emotional peak, energy 3→6/10
[FINAL CHORUS] 16 bars, everything + key change +1 semitone, maximum width, ad-lib festival, energy 12/10
[OUTRO] 8 bars, hook repeat, filter sweep down, vinyl crackle returns, fade to silence

PRODUCTION LAYERS:
[Foundation] 808 sub (mono <100Hz), sidechained -6dB
[Rhythm] 909 kick, clap 2&4, closed hats 1/16, open hats off-beat, rimshot accents
[Harmony] Supersaw stack (3 detuned), chord stabs, filter automation
[Melody] Pluck lead (pentatonic), chorus effect, reverb tail
[Vocals] Dry verse → doubled pre → tripled chorus + low/high harmonies → ad-libs
[FX] Vinyl crackle, risers, downers, vocal chops, 1/4 delay throws, crowd samples

GENRE FUSION: 70% Modern Pop + 20% Future Bass + 10% Eurodance nostalgia
VOCAL MAP: Verse(dry) → Pre(double+filter) → Chorus(triple+hall) → Bridge(telephone) → Final(maximal)
NEGATIVE: no cheesy supersaw presets, no generic "put your hands up", avoid nursery melodies
GROOVE: Straight 4x4, tight quantized, sidechain pocket
MIX: Sub mono, wide synths, upfront dry vocals, punchy drums, sidechain glue

BPM: 126, Key: F# Minor → G Minor (final chorus), Suno Version: V5
```
